# Security Reports

For confidential vulnerabilities or accidentally published sensitive material,
email **jw@osuite.ai** with the subject **Action Effect security report**.
Include the repository, commit/profile version, impact and a minimal synthetic
reproducer. Do not send live credentials, personal data or customer payloads.
Ask for an appropriate private transfer method if needed.

Non-sensitive contract disagreements and synthetic parser counterexamples can
be reported in GitHub issues. Avoid publicly disclosing a live exploitable
deployment until the affected owner has had a chance to respond.

Maintainer note (pending): the monitored address above is being confirmed. If
it does not respond, use GitHub private vulnerability reporting if it is enabled
for this repository. Do not publish a confidential report in a public issue.

These are experimental offline consumers, not a supported authorization service
or secure execution sandbox. Supported investigation scope is the current public
draft and reproducible earlier public revisions. No response-time SLA, bounty,
formal certification or production safety guarantee is offered.

Sensitive records may be restricted or withdrawn while being investigated. A
safe correction notice should preserve version history without republishing
secrets. Removing a hosted copy cannot recall third-party clones.
